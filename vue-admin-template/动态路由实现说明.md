# 动态路由实现说明

## 实现原理

### 1. 路由转换（routeUtils.ts）
- 使用 `import.meta.glob('@/view/**/*.vue')` 自动导入所有 view 组件
- 将后端返回的路由数据转换为 Vue Router 格式
- 自动处理图标、meta 信息、子路由等

### 2. 路由加载（useUser.ts）
- `setUserRoutes()`: 保存后端返回的路由数据到 localStorage
- `loadDynamicRoutes()`: 转换路由并添加到路由表
- `clearDynamicRoutes()`: 清除动态路由（退出登录时）

### 3. 路由守卫（router/index.ts）
- 检查是否已加载动态路由
- 如果未加载且有路由数据，自动加载
- 刷新页面时从 localStorage 恢复路由

### 4. 登录流程（LoginView.vue）
- 登录成功后调用 `setUserRoutes()` 保存路由数据
- 调用 `loadDynamicRoutes()` 加载路由
- 跳转到目标页面

## 使用流程

1. 用户登录
2. 后端返回路由数据（routes 字段）
3. 前端保存路由数据到 store 和 localStorage
4. 转换路由数据并添加到路由表
5. 菜单组件从 store 读取路由数据渲染菜单

## 注意事项

### 组件路径要求
后端返回的 component 路径必须与实际文件路径一致：
- 后端返回：`@/view/HomeView.vue`
- 实际文件：`src/view/HomeView.vue`

### 特殊情况
如果后端返回的路径与实际不一致，需要修改后端返回的路径。例如：
- 错误：`@/view/DataDashboard.vue`（文件不存在）
- 正确：`@/view/DataDashboard/DataDashboard.vue`（实际文件路径）

## 测试步骤

1. 清除浏览器缓存和 localStorage
2. 访问登录页面
3. 输入用户名密码登录
4. 查看控制台是否有 "动态路由加载完成" 日志
5. 检查菜单是否正确显示
6. 点击菜单项测试路由跳转
7. 刷新页面，检查路由是否保持
